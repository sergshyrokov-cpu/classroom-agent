# US-048 — коротко по-русски: счётчик неудачных попыток Декана начинается заново при блокировке

## 1. Что изменится для пользователей

**Декан**
- Блокировка входа на 15 минут снова наступает только после **пяти** неверных
  паролей подряд. Сейчас после первой блокировки хватает одного неверного пароля,
  чтобы запереть вход ещё на 15 минут (FR-001, AC-001…AC-003).
- Посторонний, знающий рабочий email Декана, больше не может держать его вход
  закрытым одним запросом раз в 15 минут — ему снова нужно пять (FR-001).
- Если два неверных пароля пришли в одну и ту же секунду, оба получают обычное
  сообщение об отказе, а не страницу ошибки (FR-003, AC-005).

**Админ и Владелец** — для них ничего не меняется. Сброс пароля Админом
по-прежнему снимает блокировку; вход Владельца уже работает правильно.

Тексты сообщений, порядок проверок, записи аудита, экраны и база данных не
меняются (FR-002).

## 2. Решения, которые нужно подтвердить

- **I-1. «Пять подряд» считаются с начала последней блокировки.** Когда пятая
  ошибка включает блокировку, счётчик в тот же момент обнуляется. Так же уже
  работает вход Владельца (FR-001).
- **I-2. Повтор при «столкновении» с любым изменением учётной записи, а не
  только с другим входом.** Если, пока шла проверка, Админ отключил Декана или
  сбросил пароль, проверка просто повторяется заново на свежих данных, и человек
  получает ответ по текущему состоянию (FR-003, AC-007).
- **I-3. Если параллельная попытка оказалась пятой и включила блокировку,** вторая
  попытка при повторе видит блокировку: ответ «вход временно заблокирован» в
  аудите, счётчик не растёт (FR-003, AC-006).
- **I-4. Не больше трёх прогонов на один запрос.** Если три раза подряд
  столкновение — показывается обычная страница ошибки, как при любом сбое.
  Столько же у Владельца (FR-004, AC-008).
- **I-5. При повторе пароль заново не проверяется, если он не менялся.** Иначе
  по времени ответа можно было бы понять, что такой логин существует: проверка
  неизвестного логина стоит одну проверку пароля, и известный не должен стоить
  две-три (FR-006, AC-009).

## 3. Открытые вопросы

Открытых вопросов нет. Единственный вопрос Story (OD-001 — чинить ли
одновременные неверные пароли) вы уже решили 2026-10-15: вариант (а), чинить в
этой Story.

## 4. Что не входит в Story

- Порядок шести проверок при входе, тексты сообщений и категории аудита — без
  изменений.
- Вход Владельца — он уже правильный.
- Сброс пароля Админом (снимает блокировку, не включает отключённую запись) — без
  изменений.
- Ограничение частоты запросов по многим учётным записям — такого требования нет.
- Столкновения в других действиях с учётной записью Декана (сброс, отключение,
  смена пароля) — остаются как есть; повторяется только проверка входа.
- Новых адресов страниц и изменений базы данных нет — этапы проектирования API и
  базы данных будут пропущены.
