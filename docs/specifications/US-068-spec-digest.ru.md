# US-068 — Сдержанное оформление обоих хостов на Bootstrap: кратко для одобрения

Версия 2: после проверки исправлены два места — имена файлов лицензии и заметки о версии
(`LICENSE.txt`, `VERSION.txt`) и точный список того, что выделяется цветом.

## 1. Что изменится для пользователей

**Админ и Декан (инсталляция), Владелец (Control Plane):**
- Все страницы обоих хостов выглядят одинаково аккуратно: таблицы с лёгкими рамками, поля и
  кнопки единого вида, спокойные рамки для сообщений (FR-002, FR-005, FR-010).
- Шапка та же: переключатель языка и, в инсталляции, баннер состояния данных. Меню, названия и
  логотипа школы нет (FR-004.1).
- Тема только светлая — даже если на компьютере включена тёмная (FR-003).
- Цветом (мягкий янтарный фон или полоска слева) выделены только: баннер состояния данных и оценка
  выше максимума (как сейчас), а в Control Plane — предупреждения Владельцу (меньше двух Админов,
  не указан адрес). Без значков, звука, всплывающих окон и мигания (FR-006).
- На телефоне страницу не надо прокручивать вбок; широкая таблица (журнал) прокручивается внутри
  своей рамки (FR-008).
- Ни одно слово на экранах не меняется, ни на украинском, ни на английском (FR-009.1).
- Защита браузера (заголовки безопасности) не ослабляется; с чужих сайтов ничего не загружается
  (FR-007, FR-009.3).

## 2. Решения, которые нужно подтвердить

- **Как доказываем «стили на каждой странице»** — тест проверяет, что у всех страниц один общий
  шаблон и никакая страница его не отключает, плюс открывает все страницы без входа и по одной
  странице каждой роли. Открывать все ~38 страниц с подготовленными данными не будем (AC-001, I-1).
- **Страницы станут шире** — сейчас текст идёт узкой колонкой (40rem в инсталляции, 28rem в
  Control Plane); теперь колонка растёт с экраном до стандартной ширины Bootstrap, журнал и отчёты
  получат больше места. Формы (вход и т. п.) остаются узкими (FR-004.2, I-2).
- **Кнопки необратимых действий красные** — подтверждение очистки данных, удаления шаблона отчёта,
  отзыва Админа, смены статуса инсталляции: красный контур, без значков (FR-005.3, I-3).
- **Ошибки в полях — просто красный текст**, как сейчас; значки Bootstrap у полей не используем
  (FR-005.4, I-4).
- **Файл Bootstrap кладём без единого изменения** и тест сверяет его отпечаток с официальным;
  вспомогательный файл для отладки (`.map`) не кладём (FR-001, AC-002, I-5).
- **Тесты, которые ищут элемент по разметке**, можно поправить, чтобы они находили тот же элемент
  с новыми классами; проверяемые ими тексты не меняются, каждая правка — в отчёте (FR-009.4, I-6).
- **Убираем автоматическую тёмную тему**, которая сейчас включается в инсталляции вслед за
  настройкой компьютера (FR-003.2, I-7).
- **Лицензия и заметка о версии — обычные текстовые файлы рядом со стилями** (`LICENSE.txt`,
  `VERSION.txt`). Как и любой файл оформления, их можно открыть в браузере по адресу; в них нет
  ничего секретного — текст лицензии, номер версии, адрес загрузки и отпечаток. Файл без
  расширения сервер не отдаёт, и это сломало бы существующие проверки безопасности (FR-001.1,
  FR-001.5, I-8).
- **Пометки «нет в Classroom», «не виден», «вибув(-ла)» и подобные остаются обычным текстом**
  без цвета: смысл несут слова, а раскраска потребовала бы менять разметку сверх оформления
  (FR-006.2, I-9).

## 3. Открытые вопросы

Нет. Оба вопроса Story решены вами 2026-11-01:
- OD-001 — файлы берём из официального выпуска Bootstrap 5.3 и сверяем по опубликованному
  отпечатку (вариант a).
- OD-002 — стандартная светлая палитра Bootstrap: синие ссылки и главная кнопка, серые таблицы
  (вариант a).

## 4. Что не входит в Story

- Меню, новые ссылки и страницы (придут с «Базовой»), поэтому без скриптов Bootstrap.
- Тёмная тема, настройка цветов, название и логотип школы.
- Изменение текстов, переводов, адресов, прав, полей форм, выгрузок, бизнес-правил.
- Изменение заголовков безопасности.
- Загрузка чего-либо с чужих сайтов, новые пакеты и инструменты.
- Оформление выгружаемых Excel-файлов и шаблонов отчётов.
- Проверка вида глазами (AC-007) входит в Story, но делает её человек на синтетических данных;
  результат записывается в отчёт и подтверждается вами при приёмке.
